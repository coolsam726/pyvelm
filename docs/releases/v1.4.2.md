# PyVELM v1.4.2

**Release date:** 2026-06-11

Patch release after **v1.4.1**: production feedback fixes for the admin shell,
module sync, workflows, and Odoo 19 document layouts.

---

## Highlights

- **Odoo 19 document layouts** — Wave, Bubble, and Folder PDF/preview headers
  (wkhtmltopdf-safe table overlays; Folder adaptive tab + title).
- **Module sync** — apps catalog status returns to idle after sync completes.
- **Bundled module discovery** — `workflow` → `contacts` and other builtin deps resolve.
- **Admin polish** — velmphp-style HTML editor toolbar, Prism readonly Code fields,
  branding page titles, form breadcrumbs, computed-field readonly, notebook relationship tabs.
- **Workflow builder** — configurable step field types and attributes.

---

## Upgrade

```bash
pip install -U "pyvelm==1.4.2"
pyvelm db migrate
```
