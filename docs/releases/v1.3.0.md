# PyVELM v1.3.0

**Release date:** 2026-06-09

Minor release after **v1.2.0**: IDE stubs for fluent ORM fields, list bulk
actions, and read-only **DetailView** pages with list row actions.

---

## Highlights

### List bulk actions

Select rows on any list (checkbox column + select-all). When unlink is
allowed and the list has no drag-reorder `sequence` field, a bulk bar offers
**Delete** by default. Custom actions:

```python
ListView.make("partner.list")
.model("res.partner")
.columns(["name"])
.bulk_actions([{"action": "unlink", "label": "Delete", "perm": "unlink"}])
```

POST `/web/records/{module}/{name}/bulk` with `{action, ids}`.

### DetailView

Read-only record pages share form layout (sections, notebooks) but open in
display mode with an **Edit** link to the paired form:

```python
ListView.make("partner.list")
.model("res.partner")
.columns(["name"])
.detail_view("partner.detail")

DetailView.make("partner.detail")
.model("res.partner")
.form_view("partner.form")
.section("identity", "Identity", ["name", "code"])
```

### IDE stubs for `Char().required()`

Run `pyvelm make:stubs` — scalar field constructors overload `Char()`,
`Text()`, `Integer()`, etc. to return `OrmFieldBuilder` so fluent chains
autocomplete in Pylance/Pyright.

## Upgrade

```bash
pip install -U "pyvelm==1.3.0"
pyvelm db migrate
```

Regenerate typing stubs if you use `make:stubs`:

```bash
pyvelm make:stubs
```
