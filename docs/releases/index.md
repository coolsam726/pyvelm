# Release notes

Use this section to track framework changes by version.

- For ongoing work on `main`, read [Unreleased](unreleased.md).
- For tagged history, use the version groups in the left navigation.
- For older published documentation trees, use [Doc versions](../versioning.md).

## Reading order

If you are upgrading an app, read from your current version upward in sequence.

Example:

1. Start at your installed version notes.
2. Read each subsequent version in order.
3. Apply migration and deployment actions at each step.
