# PyVELM v1.4.6

**Release date:** 2026-06-12

Release after **1.4.4**: schema field reactivity and docs onboarding polish.

---

## Highlights

- **Schema field reactivity** — ``live()`` / ``reactive()``, ``visible_when`` /
  ``required_when`` / ``readonly_when`` domains (including nested paths),
  ``depends_on`` inferred live drivers, and ``options_domain`` for relationship
  pickers.
- **Docs** — learning path, security guide refresh, screenshot lightbox.

---

## Upgrade

```bash
pip install -U "pyvelm==1.4.6"
pyvelm db migrate
```

Regenerate typing stubs if you use ``make:stubs``:

```bash
pyvelm make:stubs
```

See [CHANGELOG](https://github.com/coolsam726/pyvelm/blob/main/CHANGELOG.md#146--2026-06-12) for the full list.
