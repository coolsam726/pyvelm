# PyVELM v1.1.0

**Release date:** 2026-06-01

Minor release: nested **menu groups** via `MenuBranch.children()` so module
`MENUS` trees do not repeat `parent=` on every entry.

---

## Highlights

### Nested menu groups

Declare sidebar structure in one place:

```python
m.group("business", "Business", icon="square-3-stack-3d").children([
    m.group("business.directory", "Directory").children([
        m.item("business.partners", "Partners", view="partner.list"),
    ]),
])
```

- **`MenuBranch`** — returned by `m.group(...)`; chain `.children([...])` for
  items and nested groups.
- **`flatten_menus()`** — expands the tree when loading data files (parents
  before children, same as before).
- Explicit **`parent=`** is unchanged (e.g. cross-module
  `parent=("admin", "settings.reference")`).

See [Modules → Menus](../modules.md) and [Navigation](../navigation.md).

## Upgrade

```bash
pip install -U "pyvelm==1.1.0"
```

No framework schema changes. After upgrading menu declarations, **Apps → Sync**
affected modules so `ir.ui.menu` picks up parent links.
